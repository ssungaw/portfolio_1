# KANI의 자기소개 웹사이트

별명 KANI의 관심사와 목표를 소개하는 한국어 웹사이트입니다. React와 Vite로 만들었습니다. 전화번호, 주소, 생년월일 같은 개인정보는 포함하지 않습니다.

## 실행하기

Node.js 24 LTS를 설치한 뒤, 프로젝트 폴더의 터미널에서 다음 명령을 실행하세요.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 열면 됩니다. 개발 서버를 끄려면 `Ctrl + C`를 누르세요.

## 내용을 바꾸거나 확인하기

- `src/App.jsx`: 소개 문구, 관심사, 장점, 활동 안내와 목표를 수정합니다.
- `src/Profile.css`: 분홍색과 흰색 디자인, 화면 배치, 휴대전화용 스타일을 수정합니다.
- `src/index.css`: 글꼴, 공통 색상, 키보드 포커스와 같은 전체 설정을 수정합니다.
- `public/`: 나중에 직접 추가할 사진이나 작품 이미지를 넣습니다.

코드를 저장하면 개발 중인 브라우저 화면이 자동으로 바뀝니다. 현재 활동이나 작품은 아직 정하지 않아 예시를 만들지 않았으며, 나중에 소개할 내용과 사진이 생기면 추가할 수 있습니다.

## 완성 확인

```sh
npm run lint
npm run build
```

`npm run build`는 배포용 파일을 `dist/` 폴더에 만듭니다.
